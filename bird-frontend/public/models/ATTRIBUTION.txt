stork.glb
---------
Source:  three.js example assets
         https://github.com/mrdoob/three.js/blob/dev/examples/models/gltf/Stork.glb
Credit:  "Stork by mirada from rome" — the credit line carried by the three.js
         example that ships it (examples/webgl_gpgpu_birds_gltf.html).
Licence: MIT, as part of the three.js repository.
         https://github.com/mrdoob/three.js/blob/dev/LICENSE

Unmodified on disk. The application rewrites its vertex colours and material at
load time (see src/components/nature/birdModel.js); the file itself is as
distributed.

Sibling models Flamingo.glb and Parrot.glb from the same directory are drop-in
alternatives — birdModel.js derives scale and orientation from the file rather
than hardcoding them, so only the MODEL_URL constant in HeroBirdScene.jsx needs
to change.
